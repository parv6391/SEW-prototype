What this notice covers

This notice describes the current SEW prototype at this site. It does not cover GitHub's separate services or other websites linked from here.

What the prototype does

The current site is a static project page. It has no account system, contact form, analytics tool, advertising tracker, or SEW database. The page does not ask you to submit personal information. No backend data collection is active.

Any demo interaction runs in your browser. The page does not send those interactions to a SEW server. If you open a link containing a seed in its address, that full URL is part of the request made to the hosting provider.

Hosting and technical information

The site is hosted by GitHub Pages. GitHub may process technical information about requests, such as IP address, requested page, time, and device or browser details, to operate and protect its services. The project author does not receive GitHub's infrastructure logs through this page. Read GitHub's Privacy Statement for its practices.

The SEW page itself does not set cookies or use browser storage. GitHub services may use cookies or similar technologies under GitHub's own policy.

Links and public discussions

External websites have their own privacy notices. The project's GitHub issue tracker is public. Do not post personal or sensitive information there.

Changes and future data collection

This notice reflects the current static prototype. If a future model adds accounts, forms, analytics, or a backend that receives or stores personal information, this notice must be updated before that collection begins.

Questions
