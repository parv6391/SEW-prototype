# SEW Prototype
SEW (Simulation of End of World) is a research-oriented simulation project
for exploring astronomical systems, chemical anomalies, technosignatures,
and competing explanations under uncertainty.
This repository contains the current browser prototype.

## Live Prototype

https://parv6391.github.io/SEW-prototype/

## About the Prototype
The prototype is an early, deliberately small implementation of the statistical
and decision-making components being developed for SEW.

The current interactive module focuses on chemical technosignatures. It
demonstrates how synthetic observations can be compared under competing
natural and technological hypotheses, and how the result changes when the
underlying assumptions are changed.

The current implementation draws primarily on the statistical framework
developed in Paper III, while forming part of the broader SEW research
framework developed across Papers I–III.

## Research Foundation
SEW is being developed alongside three related research papers:

### Paper I
*Beyond Kardashev: A Multidimensional Framework for Civilizational
Advancement Integrating Energy, Information, Entropy with Adaptive SETI
Applications*

### Paper II
*Chemical Over-Optimization Hypothesis and the Chemical Anomaly Index (CAI)*

### Paper III
*The Chemical Improbability Principle and the Silence Threshold:
A Statistical Framework for Chemical Technosignatures*
